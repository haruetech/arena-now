# ARENA NOW — arena.showday.kr

공연 당일 사용자가 실제로 겪는 불편을 줄이는 Event-Day OS 프로토타입입니다.

## 이번 UI 개편
- 사용자 선택안 기준의 프리미엄 다크/네온 대시보드 홈
- 아레나 조감도형 AI 컨셉 이미지를 Hero 배경으로 사용
- 상단 LIVE NOW 카드 1개로 정리해 중복/겹침 제거
- 가는길 / 주변맛집 / 현장서비스 / AI 추천 / LIVE NOW / MY EVENT 빠른 메뉴
- TODAY SHOW / LIVE NOW / AI 추천 3열 대시보드
- 기존 LIVE ISSUE, PARK, EAT, TOILET, GO HOME, COMPANION, VOICE 상세 기능 유지
- 우측 하단 설정 버튼에서 Hero 핵심 문구를 개별 수정하고 localStorage에 저장 가능
- 모바일 2열 빠른 메뉴 및 1열 카드 레이아웃

## 이미지 고지
`public/arena-hero-ai.jpg`는 ARENA NOW UI 시안을 위해 생성한 AI 컨셉 이미지의 일부를 사용합니다.
실제 서울아레나 시설 및 배치와 다를 수 있으며, 공식 조감도나 언론사 이미지를 직접 복제해 포함하지 않습니다.

## 배포
GitHub `arena-now` 저장소에 기존 파일을 유지한 채 이 프로젝트 파일로 덮어쓴 후 commit/push하면 Vercel 자동 배포가 가능합니다.
