# ARENA NOW — 통합 제품 비전

> 이전 버전(풀스크린 조감도 단독 컨셉)에서 엑셀 기획
> "ARENA_NOW_공연당일_문제해결_기획정리"를 반영해 Event-Day OS 방향으로
> 업데이트한 버전입니다. 지금은 이 문서를 기준으로 실제 프로토타입을
> 구현하고 있습니다 (개발 보류 상태 아님).

## 한 문장

**공연 가는 날, 고민하지 않는 곳.**

ARENA NOW는 공연정보를 더 많이 보여주는 서비스가 아니라, 공연 전후 관객이 실제로 겪는 마찰을 줄이는 Event-Day OS입니다.

## UX 원칙

1. 3초 안에 지금 해야 할 행동을 찾게 한다.
2. 시간을 기준으로 홈 화면이 자동으로 바뀐다.
3. 자가용 사용자는 4~5시간 전부터 주차를 먼저 안내한다.
4. 수십 개 목록보다 현실적인 후보 3개를 먼저 제안한다.
5. 한 손 조작, 큰 터치영역, 짧은 문장, 높은 가독성을 기본으로 한다.
6. AI는 채팅보다 먼저 행동을 제안한다.
7. 실시간 데이터가 없으면 정확한 분 단위 대기시간을 꾸며내지 않는다.
8. 공식 안내와 관람객 제보를 절대 섞지 않는다.

## 시간 상태

D-1 → 5시간 전 → 4시간 전 → 3시간 전 → 2시간 전 → 90분 전 → 60분 전 → 입장 시작 → 공연 중 → 공연 종료.

시간대마다 PARK, EAT, TOILET, ENTER, COMPANION, GO HOME의 우선순위가 자동으로 바뀝니다.

## NOW AI

사용자에게 먼저 이동수단(자가용/대중교통/택시)을 선택받고, 공연시간과 현재 상태를 조합해 다음 행동 최대 3개를 제안합니다. 향후 날씨·주차·교통·운영사·현장 제보 데이터까지 결합합니다.

## LIVE NOW / LIVE ISSUE

관객이 현장 센서 역할을 합니다. 주차·화장실·입장·먹거리·교통 이슈를 10초 안에 제보할 수 있고, 비슷한 제보는 하나로 병합합니다.

- 🔴 긴급: 공식 안전/운영 변경 중심, 즉시 알림
- 🟠 중요: 주차 만차·교통 장애·혼잡 급증 등, 관련 사용자에게 1회
- 🟡 현장: 화장실·MD·푸드 대기 등 화면 표시 중심
- ⚪ 일반: VOICE에 축적

## 핵심 문제 영역

PARK · TOILET NOW · ENTER · BAG · WEATHER · EAT/ARENA ZONE · AROUND(상황 기반, 접근성 포함) · COMPANION TIME · MEET POINT · GO HOME · LIVE ISSUE · VOICE · SMART ALERT.

## 확장

서울아레나에서 검증한 뒤 고척·KSPO·인스파이어 등으로 확장할 수 있도록 장소 데이터와 문제 해결 로직을 분리합니다.

## 이미지·비주얼 유의사항

조감도를 실제 서비스의 메인 배경으로 사용할 경우 이미지 이용권한을 먼저
확인해야 합니다. 지금 프로토타입은 서울아레나를 그대로 재현하지 않은
추상/미래형 일러스트로 대체했으며, 운영용은 사용 허가 이미지나 자체 제작
비주얼로 교체하는 구조를 유지합니다.
